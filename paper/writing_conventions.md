# Solar Energy (Elsevier) Writing & Appendix Conventions

## Equations
- Display equations: number consecutively (1),(2),... in order referenced. Cite as "Eq. (3)".
- Variables in *italics*; math as editable text not images; simple formulae inline.
- Appendix equations: separate numbering Eq. (A.1), Eq. (A.2), (B.1)...

## Appendices
- Multiple appendices labeled A, B, C.
- Appendix tables/figures: Table A.1, Fig. A.1 (separate numbering per appendix).
- Use APPENDIX for material that ADDS to understanding (math derivations, algorithm).
- Use SUPPLEMENTARY MATERIAL (Figure S1, Table S1) for indirectly-related/completeness
  material, or if appendices would exceed ten. Supplementary is NOT typeset/copy-edited.

## Tables/Figures
- Numbered consecutively by appearance; cited in text; standalone captions; notes below table.
- Tables as editable text (not images). Vector graphics preferred; color free online.

## Methods/Reproducibility
- Enough detail in main text to reproduce; extra detail to supplementary.
- Data Availability statement (SKIPP'D public + code release).

## Front matter
- Title; authors/affiliations; Abstract (unnumbered, 1 para ~150-250w, no citations);
  Keywords (1-7); Nomenclature (symbols, Greek, sub/superscripts, abbreviations).
- Highlights: 3-5 bullets, max 85 chars each.

## Declarations (end, before refs)
- CRediT author contributions; Declaration of competing interest; Declaration of GenAI use;
  Acknowledgments; Funding.

## Style
- Numbered sections 1, 1.1, 1.1.1. Cross-ref by number. Active, precise, no hedging on facts.
- Report forecast skill vs smart-persistence (mandatory). Report PICP+PINAW together.
  Report RMSE/MAE alongside CRPS. Stratify by weather regime.
